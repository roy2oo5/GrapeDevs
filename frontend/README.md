# Singularity Frontend (ReactJS + Vite)

This directory contains the ReactJS frontend for the Singularity web template.

## Features
- **Vite + React 19**: Super-fast development server & building.
- **Glassmorphism Design System**: Modern dark theme CSS styled with custom design variables and Google Fonts (`Outfit`, `Plus Jakarta Sans`, `JetBrains Mono`).
- **Interactive API Explorer**: Live UI to test connection and CRUD routes to the FastAPI backend.
- **Lucide Icons**: Crisp SVG icons for UI components.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The application will run locally at: `http://localhost:5173`

### 3. Build for Production
```bash
npm run build
```
Output files will be generated in `dist/`.
